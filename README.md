# Movie Catalog Management

A simple desktop Movie Catalog Management System built with **Java**, **JavaFX**, and **Maven**.

## Features

* Manage movie records
* Add, view, update, and delete movies
* Search and organize movies using hash tables and tree data structures
* JavaFX graphical interface
* Local file-based data storage

## Requirements

* JDK 21
* Apache Maven

## Run

```bash
mvn clean compile
mvn javafx:run
```

Maven automatically downloads the required JavaFX dependencies.
